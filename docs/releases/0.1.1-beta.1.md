# JukeboxCli 0.1.1-beta.1

The first tagged prerelease. Local music, YouTube search and live radio in one
terminal player for Mac. Listen without downloading, or save a copy when you choose.

## In this build

- Local and online search, including search inside Now Playing.
- One editable queue for files, online tracks and radio. Sessions restore paused.
- Saved radio stations and feed lookup from station websites.
- Cover artwork in Ghostty and iTerm2, with a text fallback in Apple's Terminal.
- Local and optional online lyrics, manual matching and supplied lyric timing.
- Browser/file cookies, custom download folders, format and quality controls.

This build also fixes the clipped player border in short windows and the current
queue row showing a different duration from the player. It doesn't rewrite music
files or library tags.

## Install or update

```sh
brew tap funstuie-bit/jukeboxcli https://github.com/funstuie-bit/JukeboxCli.git
brew update
brew install funstuie-bit/jukeboxcli/jukeboxcli
# If already installed, use this instead:
brew upgrade jukeboxcli
jukeboxcli --version
jukeboxcli --doctor
```

The version should be `0.1.1-beta.1`. The project formula builds from the tagged
source and installs Node, mpv, ffmpeg and yt-dlp through Homebrew. See the
[install guide](https://github.com/funstuie-bit/JukeboxCli/blob/v0.1.1-beta.1/docs/mac-controls-and-install.md)
if another installation takes precedence over the Homebrew command.

## Testing and limits

This is a prerelease, not a claim that every Mac and terminal has been checked.
The automated suite covers playback, queue controls, layout, lyrics and installation.
Apple Silicon CI checks source installation/reinstallation and the Homebrew formula.
Check the linked workflow result before installing.

The hands-on checks for this exact build are still pending:

- Fresh Homebrew install and version/doctor checks.
- Search, play, queue, download and remove an entry without deleting its file.
- Radio playback, station removal and reconnect.
- Lyrics, restart/session restore and physical media keys.
- Artwork and short-window resizing in Ghostty, iTerm2 and Apple's Terminal.

Online services can change. Station lookup and lyrics won't find everything.
Intel Macs aren't currently part of CI. The live visualiser remains parked;
the player waveform is a precomputed whole-track display.
