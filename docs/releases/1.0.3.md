# JukeboxCli 1.0.3

Fixes app-managed yt-dlp updates failing on Macs where a cold startup takes
slightly more than ten seconds. The startup check now allows 60 seconds.

If the downloaded copy still cannot start, the error reports a timeout, exit
code or termination instead of blaming antivirus. It now says JukeboxCli, not
soundcli. Failed verification still leaves your selected provider unchanged.

```sh
brew update
brew upgrade jukeboxcli
jukeboxcli --version
```

Check the version is `1.0.3`, then choose **Settings → yt-dlp updates →
App-managed nightly**. Wait for the ready message and restart JukeboxCli.
Homebrew's yt-dlp, mpv and ffmpeg are not replaced.
