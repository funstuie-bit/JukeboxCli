# JukeboxCli 1.0.0

The first production release for macOS and Linux.

Local music, YouTube results and live radio share one editable queue. This
release includes Radio Browser searches and quick channels, five themes, six
live visualiser styles, lyrics, browser cookies and optional downloads.
Command-line options remain temporary unless you change preferences in Settings.

The wide queue now uses the full panel width. The source-update script is
executable. Existing music and settings stay where they are.

## Update

Homebrew:

```sh
brew update
brew upgrade jukeboxcli
jukeboxcli --version
```

For a current source checkout, run `sh update.sh`. The command should report
`1.0.0`. If your checkout predates the repository history cleanup and Git reports
divergent history, keep it as a backup and install from a fresh clone instead of
merging or rebasing the old history. Preserve any local edits first.

## Platform notes

The live visualiser is enabled by default on Linux. On Mac, opt in with
`JUKEBOXCLI_VISUALIZER=1 jukeboxcli`; press `v` in Now Playing to change its style.
Homebrew manages its own yt-dlp. Source installs can use the app's nightly/stable
update controls.

Automated checks cover Apple Silicon and x64 Linux. They do not certify every
terminal, browser/keyring or audio device. iTerm2 inline artwork repainting during
queue updates remains under investigation. Ghostty uses a different image path.
Visualiser filter-error recovery and broader platform acceptance remain follow-up
work; production status does not mean those limitations have disappeared.
