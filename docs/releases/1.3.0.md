# JukeboxCli 1.3.0

A better way to browse your library and put a few tracks on next. Same release
for macOS and Linux, with no new dependencies.

## In Library (`1`)

- `B` cycles songs, artists and albums. Enter opens a collection; Escape returns.
  Search and source filters still work. Browsing does not move or retag files.
- `x` marks a track; `X` clears marks. `A` appends marked tracks and `P` queues
  them next, in displayed order, without interrupting playback. With no marks,
  A/P acts on the highlighted track. Enter still plays; Space still pauses.
- `i` toggles details for the highlighted track. Text details sit alongside the
  list in wide windows, below in narrower ones, and hide in short windows.

Missing metadata appears under Unknown artist/album. Marks clear after queueing
or changing the search, source or browse view. No bulk delete, automatic download
or extra player process is involved.

Inspired by [FurqanHun/mpv-music](https://github.com/FurqanHun/mpv-music),
implemented in JukeboxCli's existing TypeScript/Ink player.

## Update

```sh
brew update
brew upgrade jukeboxcli
jukeboxcli --version
```

The version should be `1.3.0`. Quit any running copy and reopen it after upgrading.
Source installs can run `./update.sh` from their checkout. Existing music,
settings and optional visualiser packs are kept.

Genre browsing, playlist-file import/export and a session-log viewer are not
included in this release.
