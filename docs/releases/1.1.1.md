# JukeboxCli 1.1.1

Fixes an invisible background player continuing to play after JukeboxCli exits.

- On macOS and Linux, mpv now exits when its parent app disappears, including
  crashes, terminal hangups and force-kills.
- Uses an inherited lifetime pipe, independent of playback controls and the
  visualiser. No polling process or extra dependency is needed.
- Adds ten real-player regression tests covering five exit modes with the
  visualiser on and off. Test playback is generated locally and inaudible.

Restart JukeboxCli after updating. This prevents new orphaned players; it does
not search for or terminate players left behind by an older version.

## Update

Homebrew on macOS:

```sh
brew update
brew upgrade jukeboxcli
jukeboxcli --version
```

For a source installation, run `./update.sh` from your checkout.
The version should be `1.1.1`. Music and settings are unchanged.
