# JukeboxCli 1.0.1

Homebrew users can now use yt-dlp nightly without waiting for Homebrew to update.

1. Update JukeboxCli: `brew update` then `brew upgrade jukeboxcli`.
2. Open Settings → yt-dlp updates → **App-managed nightly**.
3. Wait for the ready message, then close and reopen JukeboxCli.

The nightly lives in JukeboxCli's cache. Homebrew's yt-dlp, mpv and ffmpeg are
not overwritten. Choose **System / package manager** and restart to switch back.
**App-managed stable** is also available.

Settings shows the executable active for this launch and the choice for the
next one. Doctor reports the provider, requested channel, installed app version
and any staged update. A selected channel alone isn't proof that version is
running.

Updates are checked for startup success and applied on restart, never over an
active download or stream lookup. Failed downloads leave the saved preference
unchanged. Existing installations keep their default provider until you opt in.

Verification includes isolated provider/restart tests, Settings navigation,
failed updates, returning to system ownership, doctor output and serialized
staging. `npx tsx scripts/smoke-ytdlp-provider.ts --download-nightly` explicitly
downloads and runs the official nightly in a temporary profile and checks that
the system executable is unchanged; it never accesses music or browser cookies.
