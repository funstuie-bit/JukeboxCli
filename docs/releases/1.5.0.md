# JukeboxCli 1.5.0

A cleaner player, browsing artwork and settings that stay where you put them.
One release for Mac and Linux. Existing defaults stay unchanged.

## What's new

- **Browsing artwork:** optional cover previews in Library collections and
  downloaded Playlists. Highlighting previews only; Enter still plays. Needs a
  wide content pane and a terminal with suitable artwork support.
- **Clean player:** larger art, fewer labels and an editable Up Next list.
  Press `7` for the full queue. Lyrics, search and visualisers remain available.
- **Theme editor:** preview palettes, backgrounds, borders, contrast and accent
  colours before saving. Escape discards the draft.
- **Custom shortcuts:** change transport, player and queue controls, with
  conflict checks and updated help. Text entry, navigation and Ctrl+C stay fixed.
- **Playlist continuation:** opt in, then start a track inside a Discover
  album/playlist. Near the queue's end, append the next metadata page without
  resetting your queue. No automatic music downloads. Requests are bounded and
  cancelled on stop or context replacement; `C` in Queue retries a failed page.
- **Settings menus:** all options show when the window has room. Toggling keeps
  the same row selected, and returning from an editor keeps your place too.

Find visuals in **Settings → Player appearance**; shortcuts and continuation
are under **Keyboard and mouse**. No changes to your existing music or settings.
See the [feature guide](https://github.com/funstuie-bit/JukeboxCli/blob/v1.5.0/docs/player-polish.md)
for controls, supported terminals and queue-continuation limits.

Inspired by [Orpheus](https://github.com/Cabritto-Corps/orpheus), implemented
independently in JukeboxCli's existing stack. No Orpheus code or assets included.

## Update

```sh
brew update
brew upgrade jukeboxcli
jukeboxcli --version
```

Expect `1.5.0`. Quit and reopen after upgrading. Source installs can run
`./update.sh` from their checkout. The new appearance/continuation options are
off until enabled; Classic remains the default layout.

Automated checks do not cover every terminal, external service or long listening
session. Physical artwork rendering and long online playlists still benefit
from hands-on testing.
