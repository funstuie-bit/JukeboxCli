# JukeboxCli 1.1.0

This release adds optional old-school Winamp/MilkDrop-style fullscreen effects
on Linux.

- Press uppercase `F` in Now Playing, or choose **Settings → Player appearance
  → Fullscreen effects**, to open a separate projectM graphics window.
- Playback, the queue and the compact terminal visualiser continue unchanged.
- JukeboxCLI selects the active PipeWire/PulseAudio output monitor without
  changing the default microphone or opening another copy of the song.
- The launcher skips projectM's branded introduction, begins with a shuffled
  community preset and closes its companion process when JukeboxCLI exits.
- projectM remains optional. If it is missing, the app explains which package to
  install; every other player feature continues normally.

On Arch Linux, add the optional frontend with:

```sh
sudo pacman -S --needed projectm-pulseaudio
```

The first implementation listens to the active system output, so audio from
another application can also affect the animation. The fullscreen mode is Linux
only in this release.

## Update

Homebrew installation on macOS:

```sh
brew update
brew upgrade jukeboxcli
jukeboxcli --version
```

Source installation on macOS or Linux:

```sh
cd JukeboxCli
./update.sh
jukeboxcli --version
```

The version should be `1.1.0`.
