# JukeboxCli 1.0.2

The live visualiser now starts automatically on Mac as well as Linux. Launch
`jukeboxcli`, open the player with `m`, and press lowercase `v` to cycle its six
styles. Uppercase `V` controls decorative animation instead. No launch flag is
needed. `JUKEBOXCLI_VISUALIZER=0 jukeboxcli` remains available to disable analysis.

Homebrew users can also choose **Settings → yt-dlp updates → App-managed nightly**
or **App-managed stable**. Wait for the ready message, then restart JukeboxCli.
This uses a separate cache copy and leaves Homebrew's yt-dlp, mpv and ffmpeg alone.
Choose **System / package manager** and restart to switch back.

Update with:

```sh
brew update
brew upgrade jukeboxcli
jukeboxcli --version
```

The version should read `1.0.2`. If it still shows an old version, check for an
older npm installation shadowing the Homebrew command.

The onboarding CI test now waits for input handlers to attach before sending
keys. Its configuration-persistence assertions remain in place. Mac visualiser
verification includes a real muted mpv test using the normal default launch.
