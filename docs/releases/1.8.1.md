# JukeboxCli 1.8.1

Clearer Home thumbnails for Mac and Linux, with the same music, queues and settings.

## Artwork fixes

Recent listening and saved stations use sharp native thumbnails on supported
terminals, alongside the featured cover. Each visible image has its own lifetime;
opening and closing foreground views restores the underlying artwork.

Long titles truncate without squeezing thumbnail boxes or wrapping their pixel
rows over headings and neighbouring items. Block and simple artwork remain the
fallbacks for other terminals and overlays.

Foot/Sixel uses an adaptive 256-colour palette to preserve photographic colours.
Newly loaded or moved images paint after the terminal text has flushed, keeping
them visible as other artwork finishes loading. Unchanged images stay in place.

The build/test-only source-map-js dependency is patched to 1.2.2. There are no new
system dependencies or automatic preference changes.

## Update

```sh
brew update
brew upgrade jukeboxcli
jukeboxcli --version
```

Expect **1.8.1**, then quit and reopen JukeboxCli. Source installations can use
`./update.sh`. Music, queues, browser preferences and optional preset packs are kept.

## Checks and limits

The accepted runtime passed 947 tests with 5 skipped on Arch, plus typecheck,
build/import validation, the production redraw memory guard and real Sixel
extraction. Real Foot captures verified multiple covers, initial loading and
hide/restore. The installed app was checked with isolated history fixtures;
Linux user feedback confirmed the improved thumbnails.

Release checks cover Mac and Linux installations; Mac also builds and tests the
pinned Homebrew formula. Native image quality still depends on the terminal.
Broader physical Mac and long-session memory/GPU acceptance remain ongoing.
