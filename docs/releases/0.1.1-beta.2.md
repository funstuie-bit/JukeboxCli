# JukeboxCli 0.1.1-beta.2

Fixes a bug reported on Reddit: command-line flags were being saved as permanent
preferences before the player opened.

`--output-dir`, `--cookies`, `--cookies-from-browser`, `--format`, quality,
templates, delays and retries now apply only to the current launch. Downloads
and streaming use those temporary values. Onboarding and unrelated Settings
changes won't save them. Change a field in Settings to a different value if
you want that preference saved for future launches.

The help text now states this directly. Existing values saved by earlier
versions aren't reset automatically. If a previous command changed your download
folder or other preferences, restore your preferred values in Settings once.
Music files and library entries are not moved or deleted by this fix.

This release also adds the funstuie-bit contributor credit and removes the old
`soundcli` command alias from new source/package installs. The original soundcli
author and MIT notice are retained. Homebrew already installed only `jukeboxcli`.

## Update

```sh
brew update
brew upgrade jukeboxcli
jukeboxcli --version
```

The version should be `0.1.1-beta.2`. For a source installation, run `./update.sh`
in your clean checkout instead. Restart the player after updating.

## Verification

Regression tests cover unchanged config files after temporary overrides, next-launch
defaults, onboarding, unrelated preference saves, deliberate edits, cleared values,
serialized writes and effective config passed to downloads and streaming.
The full suite, build and isolated installer checks are run before publication.
Real-terminal acceptance testing remains separate from automated checks.
