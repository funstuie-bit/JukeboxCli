# JukeboxCli 1.9.0

More useful on a laptop, with listening tools and controls that are easier to
find. Mac and Linux use the same release and the same mixed-source queue.

## What changed

- Home keeps a compact jukebox in smaller windows. Roomy layouts show real
  recent/Continue, saved-station and local-playlist cover shelves. Clean player
  layout gives cover art and the queue more balanced space.
- **Z** opens a three-line mini-player. **Ctrl+B** hides/shows the sidebar.
  Tiny windows use mini mode automatically; enlarge the window to return.
- **Ctrl+K** opens searchable Commands: player controls, sections, chapters and
  queue actions. Existing custom bindings and text-field editing chords stay.
- **Ctrl+E** opens Listening tools, also available in Settings. It has reported
  audio format details, sleep timers and a bypass-by-default ten-band EQ.
- Sleep after 15/30/60/90 minutes, custom minutes, the current track or a known
  album boundary. Expiry pauses/disconnects and retains the queue. Explicit Play
  resumes; timers don't carry across app restarts. mpv is required.
- EQ offers presets/custom gains and explicit Save. Its separate filter keeps
  spectrum analysis intact. Flat bypasses EQ; boosts reserve headroom.
- Shared palette previews update the interface chrome, lists, menus and player.
  Escape/leaving discards a draft. Built-in solid palettes have contrast checks.
- Click mode adds hover feedback and timeline/volume dragging. Shift-drag still
  selects terminal text. LIVE streams never expose a seek target.
- Per-media resume points add Continue on Home and Resume/Start again in video
  actions. Wide video results show available channel/date/views/duration, with
  compact rows in narrow windows. Real chapter metadata is available in Commands.
- Optional audio download-size estimates wait for a settled video selection,
  cancel when you move and keep a bounded in-memory cache. Off by default;
  no media is downloaded. Transcoded/missing sizes are labelled honestly.
- An optional process-owned Mac helper observes sleep, supported output
  disconnects and Low Power Mode. Linux observes logind sleep when available.
  Wake never starts playback. Manual low-power mode reduces visual redraws.

Cookies, mouse settings, music and existing queues keep their saved choices.
No new account requirement, browser access, permanent daemon or audio rerouting.
Interaction inspiration: [Musinator](https://github.com/smanookian/musinator),
[TubeTUI](https://github.com/polblancoo/tubetui) and
[Cloofy](https://github.com/parda21/cloofy), implemented independently.

## Checks and limits

986 tests passed with 6 skipped on Apple Silicon macOS, plus typecheck, build,
distribution import and production redraw checks. Isolated install, relocation
and reinstall passed. Real muted local/EQ/spectrum/timer, ICY radio and anonymous
YouTube video/audio/video checks retained one mpv, position and queue.
The built CLI and Mac helper lifetime were also checked in an isolated terminal.
Final Mac/Linux installation CI gates publication.

Physical lid/headphone/Bluetooth behaviour and longer resource acceptance remain
device-specific. Linux doesn't claim output-disconnect or system low-power
detection; missing helpers are reported. Low-power visuals don't disable mpv's
analysis or alter audio quality. Enabled EQ processes at 48 kHz; no bit-perfect
or universal clipping guarantee. Source restrictions can still affect YouTube.
See [controls and platform limits](https://github.com/funstuie-bit/JukeboxCli/blob/v1.9.0/docs/listening-tools.md).

## Update

```sh
brew update
brew upgrade jukeboxcli
jukeboxcli --version
```

Expect **1.9.0**, then quit/reopen. Source installs can use `./update.sh`.
