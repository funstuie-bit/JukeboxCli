# JukeboxCli 1.0.4

This release makes Linux source installation and terminal paste handling safer.

- A normal `./install.sh` now uses `$HOME/.local` when npm's configured global
  prefix is system-owned, as it commonly is on Arch Linux. It does not require
  running the installer as root.
- JukeboxCli now keeps a large terminal paste together as one event. A `q`
  inside pasted text cannot quit the app midway and leave the remainder for the
  shell to execute. Pasting into text fields and first-run setup still works.
- The locked test dependencies are refreshed, with a zero-vulnerability audit
  and explicit npm 12 approval for the two required esbuild install scripts.

Existing music, queues, settings and app-managed tools are unchanged.

## Update

Homebrew installation on macOS:

```sh
brew update
brew upgrade jukeboxcli
jukeboxcli --version
```

Source installation on macOS or Linux:

```sh
cd JukeboxCli
./update.sh
jukeboxcli --version
```

The version should be `1.0.4`. Run `jukeboxcli --doctor` to verify the active
command and media tools.
