# JukeboxCli 1.6.2

A follow-up patch for missing YouTube video sound and browser-cookie selection.
One release for Mac and Linux; your music and preferences are kept.

## What's fixed

- Keep HLS soundtracks when yt-dlp hasn't identified their codec yet. If mpv
  drops external audio while loading a video playlist, attach it explicitly to
  the same player. The existing single retry can choose an HLS soundtrack when
  a YouTube direct-audio link fails. Configured cookies are retained.
- Find numbered, Developer Edition, ESR and custom Firefox profiles, including
  profiles.ini paths. Offer Firefox/Chrome automatic-profile choices and manual
  browser/profile entry even if detection finds nothing. Report permission and
  cookie-read errors without exposing private paths or extractor output.
- Clear cached stream links when cookie selection changes, and check cookie-file
  paths before saving them. A selected browser is not proof of a working login.
- Make the active mouse mode clearer in Settings. Clicks are still opt-in:
  **9 Settings → Keyboard and mouse → Mouse: click**. Wheel mode only scrolls;
  Shift-drag selects terminal text in click mode. No preferences are reset.

## Update

```sh
brew update
brew upgrade jukeboxcli
jukeboxcli --version
```

Expect **1.6.2**, then quit and reopen JukeboxCli. Source installs can use
`./update.sh` from their checkout.

## Checks and limits

903 tests passed with 6 skipped on Apple Silicon macOS, plus typecheck, build and
distribution/production checks. Real mpv acceptance uses an isolated profile,
zero volume and separate streams; it checks video/audio/video switching, one
player, retained queue/position, decoded audio output and cleanup. The reported
Cyberpunk Hacker Music result was reproduced with yt-dlp nightly 2026.10.10.233141.

Mac/Linux install checks cover release packaging; Mac also installs/tests the
pinned Homebrew formula. Browser detection is tested with fixtures, not a claim
that cookies or login were verified on your machine. Source availability, browser
permissions/decryption, physical audio devices and wider live-video support
remain outside those automated guarantees.
