# JukeboxCli 0.1.1-beta.4

This beta brings the Linux work back into the main JukeboxCli release: stable
terminal artwork, six audio-reactive visualisers, Radio Browser discovery and a
balanced two-column full-screen player.

## Listening additions

- Press `M` in Radio for quick Lo-fi, Synthwave, Ambient, Chillout, Jazz,
  Classical, House, Drum & Bass, Reggae and Rock searches.
- Press `B` for popular stations, or browse by genre and country. Results are
  supplied by Radio Browser and stay temporary until you save them.
- Cycle Classic Peak, Smooth, Bass Mirror, Outline, Bricks and Mosaic with `v`.
- Cycle Lavender, Calm, Ember, Ocean and Forest player themes with `T`.

## Linux and downloads

- Foot uses stable Sixel artwork while live player rows update.
- The visualiser is on by default on Linux and works with live radio.
- Chromium-family cookie extraction explicitly uses an active GNOME Keyring,
  avoiding anonymous requests that can be rate-limited despite Premium login.
- App-managed yt-dlp defaults to nightly. Settings can update now or switch to
  stable; `jukeboxcli --doctor` reports the selected channel and installed
  version. Package-manager installations keep control of their own yt-dlp.

Radio stations and metadata are community supplied, so individual streams and
artwork can still change or disappear independently of JukeboxCli.
