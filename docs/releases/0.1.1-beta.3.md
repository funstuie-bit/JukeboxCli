# JukeboxCli 0.1.1-beta.3

Fixes the crash when opening Settings → Download pacing:
`Rendered more hooks than during the previous render`.
The conversion screen had the same hook-order mistake and is fixed too.

Regression tests cover opening pacing, changing and saving a field, reopening
and leaving the page, and entering and leaving an empty-library conversion.

Download speed and saved settings are unchanged. Pacing defaults to a 1–3 second
pause between downloads; it doesn't limit transfer speed. Slow downloads on a
particular machine still need separate diagnosis.

## Update

```sh
brew update
brew upgrade jukeboxcli
jukeboxcli --version
```

The version should be `0.1.1-beta.3`. Source installs can run `./update.sh` in
their clean checkout. Restart JukeboxCli after updating.
