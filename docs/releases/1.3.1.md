# JukeboxCli 1.3.1

Five [Studay FM](https://www.studayfm.com/) AI radio stations, ready to play on
Mac and Linux. No new dependencies or accounts needed.

## Listen

Press `9`, then uppercase `S` to browse:

- Studay FM
- StuLoFiDay
- Yacht Zone
- Tokyo Jazz
- C'est Magnifistu

Enter plays the highlighted station, `A` appends it to the queue, `P` queues it
next and `f` saves it as a favourite. Browsing does not start playback, download
audio or save favourites automatically.

Pasting the Studay FM website with `R` also finds all five feeds. Direct stream
links pick up the station name and artwork. Artwork is the station's static
image; track metadata uses the existing radio player, not the website's
programme schedule. All five feeds passed live audio checks for this release,
though availability still depends on the station.

## Update

```sh
brew update
brew upgrade jukeboxcli
jukeboxcli --version
```

The version should be `1.3.1`. Quit any running copy and reopen after upgrading.
Source installs can run `./update.sh` from their checkout. Existing music,
settings and optional visualiser packs are kept.
