# Repository presentation

The README uses the supplied repo-kit layout and theme strip, with current
installation instructions and an explicit Mac/Linux feature split.

- `assets/hero.svg` is an editable, version-independent header adapted from the
  kit. Release information belongs in the live badge and release notes, not
  baked into the artwork.
- `assets/themes.png` is a palette illustration, not a player screenshot.
- `assets/social-preview.png` is the kit's 1280×640 promotional illustration.
  Its queue is illustrative, not a capture of the current interface.
- The existing demo and terminal screenshots show the real app. Keep the
  Ghostty and Apple Terminal captures beneath their matching descriptions.

To use the social card, upload `assets/social-preview.png` under the repository's
Settings → General → Social preview. Tracking the image alone does not change
GitHub's repository setting.

Do not commit the design archive, its bundled application snapshot, export
support scripts or private working notes. Update the existing app documentation;
do not replace source files with the kit's older snapshot.
