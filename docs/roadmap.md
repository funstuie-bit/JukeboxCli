# Roadmap

## Next

- Finish public documentation and a reproducible prerelease workflow.
- Publish a clearly labelled prerelease after verification; pin Homebrew to that
  exact source snapshot and attach a small video demo.
- Broaden clean-install, terminal artwork and physical media-key checks on Intel
  and Apple Silicon Macs.
- Investigate timing-sensitive UI tests and track development-tool advisories.

## Later

- Revisit the isolated [visualiser prototype](visualiser-prototype.md) after
  higher-priority work; require sustained playback/performance and visual checks
  before integrating it.
- Explore cover-derived colours and additional terminal capabilities.
- Consider broader platform support only with installation and playback tests.

## Not planned

- Separate YouTube Music sign-in, account likes or personalised-radio sync.
  Existing browser cookies remain the playback/download authentication route.
- DRM bypass, arbitrary website script execution or universal station discovery.
- Automatic downloads just from playing or queueing a track.
- A UI-framework rewrite solely to match another player's appearance.

See [feature status](../FEATURES.md) for what is already implemented.
